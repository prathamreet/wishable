## 🎨 Design System

### Color Palette
```css
Background: white
Primary Text: neutral-950 (almost black)
Secondary Text: neutral-600 (gray)
Borders: neutral-200 / neutral-900
Error: red-600 / red-50
Success: green-600 / green-50
```

### Typography
- System fonts: `-apple-system, BlinkMacSystemFont, 'Segoe UI', system-ui, sans-serif`
- Headings: `font-semibold tracking-tight`
- Clean hierarchy through font size/weight only
- NO gradient text effects

### Components
```css
.card { border: 1px solid neutral-200 }
.btn-primary { bg-neutral-950, text-white }
.btn-secondary { border: 1px solid neutral-900 }
.form-input { border: 1px solid neutral-300 }
```

### Removed Elements
- ❌ All emojis (🎮, 🛒, 📱, ⚙️, 🏠, etc.)
- ❌ All gradients (`bg-gradient-to-*`)
- ❌ All blur effects (`backdrop-blur-*`)
- ❌ Glassy transparency (`bg-white/10`)
- ❌ Colorful hover glows
- ❌ Scale transforms on hover
- ❌ Complex animations

### Kept Elements
- ✅ Simple border hover states
- ✅ Fast color transitions (0.2s)
- ✅ Clean focus states
- ✅ Minimal fade-in animation
